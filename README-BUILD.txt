MY EXCEL - ANDROID APK PROJECT

1. Install Android Studio on a Windows/Mac/Linux computer.
2. Extract this ZIP.
3. Open the extracted MyExcel_Full_Android_Project folder in Android Studio.
4. Wait for Gradle Sync to finish.
5. Select Build > Build APK(s).
6. APK will normally be at:
   app/build/outputs/apk/debug/app-debug.apk
7. Copy the APK to your Android phone and install it.

The app is a simple Excel-like spreadsheet with:
- editable cells
- formulas: =A1+B1
- SUM and AVERAGE
- CSV export
- JSON save/open
- 40 rows x 15 columns
